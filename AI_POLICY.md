> Under development, subject to change

You are allowed to create/modify with AI and add said changes to the codebase as long as:

1. You are able to explain,edit , maintain and secure said code by yourself without any help of external tools
2. Said code is inspected properly and follows standard quality & security practises

Regardless if an LLM generates and/or publishes code on your behalf, you are still responsible for said code.
Therefore you are also responsible of the vulnerabilities and security risks said code carries.

* Common IaC misconfigurations are _generally_ not punished since humans are prone to comitting errors ( *however they can be punished depending on the severity)
* Malicious code that tries to make a system vulnerable on purpose  ( such as weakining a service and/or executing untrusted code) is against the rules and will lead to a severe punishment.
